# ضبط تماس (CallRecorder) — نسخه‌ی ۲

اپلیکیشن اندروید برای ضبط خودکار تماس‌ها با کیفیت HD (فرمت AAC / M4A)، بازنویسی‌شده برای اندروید ۱۴ تا ۱۶.
ساخته‌شده با Kotlin و Jetpack Compose، با رابط فارسی (راست‌به‌چپ).

## ساخت APK با GitHub

1. در GitHub یک مخزن (Repository) جدید بسازید.
2. همه‌ی فایل‌های این پوشه (از جمله پوشه‌ی `.github`) را در مخزن آپلود کنید.
3. به تب **Actions** بروید. ساخت به‌صورت خودکار شروع می‌شود (یا **Build APK → Run workflow**).
4. پس از پایان، از بخش **Artifacts** فایل `CallRecorder-apk` را دانلود کنید.
5. APK را روی گوشی نصب کنید (نصب از منابع ناشناس باید مجاز باشد).

## امضای ثابت (برای نصب نسخه‌ی جدید روی نسخه‌ی قبلی)

بدون کلید امضا، APK دیباگ ساخته می‌شود که هر بار کلید تازه‌ای دارد؛ پس نسخه‌ی بعدی روی قبلی نصب نمی‌شود.

1. روی ویندوز با JDK نصب‌شده در PowerShell اجرا کنید: `.\scripts\make-keystore.ps1`
   فایل `callrecorder-release.jks` ساخته می‌شود. **از آن پشتیبان امن بگیرید** و هرگز در GitHub آپلود نکنید.
2. در GitHub: **Settings → Secrets and variables → Actions** و این چهار Secret را بسازید:
   `KEYSTORE_BASE64` (خروجی اسکریپت)، `KEYSTORE_PASSWORD`، `KEY_ALIAS` (مقدار: `callrecorder`)، `KEY_PASSWORD`.
3. یک بار Actions را اجرا کنید. خروجی `app-release.apk` امضاشده است.

برای هر نسخه‌ی جدید، `versionCode` را در `app/build.gradle.kts` یکی زیاد کنید.

## نحوه‌ی کار در اندروید ۱۴ تا ۱۶

در این نسخه‌ها سیستم اجازه نمی‌دهد با شروع تماس، از پس‌زمینه سرویس میکروفون راه‌اندازی شود. به همین دلیل:

- **سرویس پایش دائمی** (`CallMonitorService`) وقتی برنامه را باز می‌کنید روشن می‌شود و با اعلان دائمی در پس‌زمینه می‌ماند. چون در حالتی شروع شده که برنامه روی صفحه بود، دسترسی میکروفونش در پس‌زمینه هم باقی می‌ماند.
- وضعیت تماس با `TelephonyCallback` شنیده می‌شود و ضبط از داخل همین سرویس شروع می‌شود.
- **تشخیص بی‌صدایی:** برنامه هر ثانیه دامنه‌ی صدا را بررسی می‌کند. اگر منبع صدا ۴ ثانیه کاملاً بی‌صدا بماند، خودکار منبع بعدی را امتحان می‌کند (`VOICE_CALL` ← `VOICE_RECOGNITION` ← `MIC` ← `VOICE_COMMUNICATION`).
- بخش «گزارش آخرین ضبط» نشان می‌دهد کدام منبع کار کرد و بیشینه‌ی دامنه چقدر بود (صفر یعنی بی‌صدا).
- شماره و جهت تماس (ورودی/خروجی) چند ثانیه بعد از پایان تماس از Call Log خوانده می‌شود و نام فایل اصلاح می‌شود.
- **بعد از ریستارت** یا بسته شدن برنامه توسط سیستم، سرویس خودکار بالا نمی‌آید (محدودیت اندروید). یک اعلان نمایش داده می‌شود؛ با زدن آن یا باز کردن برنامه، پایش دوباره روشن می‌شود.

| HD (پیش‌فرض) | ۴۴.۱ kHz | ۱۲۸ kbps | ۱ MB در دقیقه |

## تنظیمات لازم روی گوشی (Honor / MagicOS)

- همه‌ی مجوزها را بدهید (میکروفون، تلفن، گزارش تماس‌ها، اعلان‌ها).
- تنظیمات ← باتری ← راه‌اندازی برنامه (App launch): برنامه را «مدیریت دستی» کنید و هر سه گزینه را روشن کنید.
- برنامه را از بهینه‌سازی باتری مستثنا کنید.
- نام منوها در نسخه‌ی شما ممکن است کمی فرق کند.

## محدودیت‌ها (مهم)

- **این نسخه روی Honor X9d با اندروید ۱۶ تست نشده است.** اینکه سیستم هنگام تماس چه صدایی به برنامه‌های جانبی می‌دهد، به تولیدکننده بستگی دارد و باید روی گوشی خودتان امتحان شود.
- ممکن است فقط صدای شما ضبط شود. در این حالت تماس را روی بلندگو بگذارید.
- ضبط‌ها داخل حافظه‌ی اختصاصی برنامه ذخیره می‌شوند و با حذف برنامه پاک می‌شوند. با دکمه‌ی اشتراک‌گذاری می‌توانید آن‌ها را بیرون ببرید.
- ضبط‌های کوتاه‌تر از ۲ ثانیه یا ناموفق خودکار حذف می‌شوند.

## ملاحظات قانونی

ضبط مکالمه بدون اطلاع یا رضایت طرف مقابل در بسیاری از کشورها غیرقانونی است. مسئولیت استفاده بر عهده‌ی شماست. هنگام ضبط، اعلان دائمی نمایش داده می‌شود و برنامه آیکن مخفی ندارد.

## ساختار پروژه

```
app/src/main/java/com/majid/callrecorder/
  MainActivity.kt              رابط کاربری، تنظیمات، لیست ضبط‌ها
  CallMonitorService.kt        سرویس پایش تماس و ضبط (MediaRecorder)
  BootReceiver.kt              یادآوری فعال‌سازی بعد از ریستارت
  Notifs.kt                    کانال‌ها و اعلان‌ها
  RecordingStore.kt            خواندن فایل‌های ضبط‌شده
  Prefs.kt                     تنظیمات، کیفیت و منبع صدا
  CallAccessibilityService.kt  سرویس اختیاری
.github/workflows/build.yml    ساخت خودکار APK
scripts/make-keystore.ps1      ساخت کلید امضا
```
